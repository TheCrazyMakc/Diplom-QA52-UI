# Дипломный проект: Автоматизация тестирования веб-приложения Stellar Burgers

Данный проект содержит пакет автотестов для проверки ключевого функционала веб-приложения **Stellar Burgers**. Тестирование реализовано на фреймворке **Pytest** с использованием библиотеки **Selenium WebDriver** и паттерна **Page Object Model (POM)**.

## 🚀 Реализованный функционал и покрытие

Проект разделен на две логические части:
1. **Основная часть (`test_main_page.py`)**: Проверка работы Конструктора, переходов по разделам сайта, кликов по ингредиентам и базовой логики главной страницы.
2. **Лента заказов (`test_order_feed.py`)**: Проверка динамического обновления счетчиков ("Выполнено за все время", "Выполнено за сегодня") и отображения созданных заказов в Ленте.

## 📦 Инструкция по развертыванию проекта

### 1. Клонирование и подготовка окружения
Убедитесь, что у вас установлен Python 3.10+. Создайте и активируйте виртуальное окружение, после чего установите зависимости:
```bash
pip install -r requirements.txt
```

### 2. Запуск тестов

**Запуск всех тестов проекта в обоих браузерах подряд:**
```bash
python -m pytest tests/ -v
```

**Запуск файла только в Chrome:**
```bash
python -m pytest tests/test_order_feed.py -k "chrome" -v
```

**Запуск файла только в Firefox:**
```bash
python -m pytest tests/test_main_page.py -k "firefox" -v
```
